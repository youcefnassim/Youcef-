Comment l'installer sur Gmail :

  1. Sélectionnez toute la signature ci-dessous (le texte et les icônes) avec votre souris, ou faites Ctrl + A puis Ctrl + C pour la copier.
  2. Ouvrez Gmail > Paramètres (l'icône engrenage) > Voir tous les paramètres.
  3. Descendez jusqu'à la section "Signature".
  4. Créez une nouvelle signature, collez (Ctrl + V) le contenu dans la boîte de texte.
  5. Enregistrez les modifications tout en bas de la page.
